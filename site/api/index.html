API reference

The crates that a synth driver or another Rust project uses, documented from the source.

Crates
  • oscyl-driverThe driver contract: Driver, SessionOp, SessionEvent, the SysEx helpers and the request engine
  • oscyl-midiFind and open a synth, and run operations on it. It holds every driver that Oscyl has
  • oscyl-coreRead and write .oscyllib library files
  • oscyl-conformanceThe checks every driver passes against its simulator

To add the crates to a project, see Use Oscyl's crates in your own project. To write a driver, start with Your first driver.
