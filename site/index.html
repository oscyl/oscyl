Your synth's sounds, in order.

Oscyl is an open-source librarian and sound editor for hardware synths. It reads every program, draws each stage of the sound, and writes back only what you changed.

Download Source Try it without a synth

Pre-alpha. Early builds for Linux and the command line are on the Releases page. For Android, build from source for now.

Library

Every program, with its picture.

Read the synth once and keep working with it unplugged. Rename, reorder, search and move programs between libraries; one island holds navigation, search, Save and Undo.

  • Works offlineYes
  • Vendor library filesRead and written unchanged
  • Own format.oscyllib
Edit

Follow the signal, stage by stage.

Voice, oscillators, mixer, filter, envelopes, effects: each stage has a live graph and every parameter. Each change plays on the synth as you make it, and nothing is stored until you say so.

  • Cutoff618 was 431
  • AuditionLive, nothing stored
  • On a phoneA stage rail under your thumb
Compare

The saved sound never leaves.

Every dial keeps its saved value on its face, and every stage counts its edits. Hold Compare and the synth plays the saved program; let go and your edit is back.

  • HistoryEvery step, undoable
  • Snapshots3 to store and recall
Generate

Six new sounds from four dials.

Pick a character and shape it with Bright, Movement, Grit and Ambience. Hold the stages you like, vary a sound, breed two together, and keep the ones worth a slot.

Sync

Nothing is written by surprise.

Before a sync, Oscyl lists every change and backs up the slots it will touch. Then it writes only those slots and waits for the synth to confirm each one.

  • Slots writtenEdited ones only
  • BackupBefore every sync
  • Factory slotsNever changed

Try it

No synth on the desk? Use the demo one.

The simulated synth answers like a real one, with no sound. You need Rust 1.92 or newer. Android, iOS and Flatpak builds

git clone https://github.com/oscyl/oscyl && cd oscyl
# Linux, macOS, Windows
cargo run -p oscyl-cli -- --simulator info
# the Linux app
cargo run -p oscyl-gtk -- --simulator
