Your synth's sounds, in order.

Oscyl is an open-source librarian and sound editor for hardware synths. It reads every program, shows each stage of the sound as a picture, and writes back only what you changed, after backing it up.

Get the source on GitHub Try it without a synth

Pre-alpha. No release yet: today you build it from source. Linux, Android, iOS and the command line.

See it move

Every picture here is drawn by the apps themselves.

The island

Navigation and Save float over your programs. Save counts your edits, shows its progress and turns into Sync.

The stage rail

One thumb on the right edge: tap a stage, or hold and slide to read every stage with its values.

Search and undo

The island becomes the search field, and the place where a removed program comes back.

Edit along the signal

The curve moves with the dial, the saved curve stays behind it, and the stage counts the edit.

Hold to compare

Hold, and the synth plays the saved version. Let go, and your edit is back.

Generate

Four dials shape a character. Oscyl deals six sounds; keep the ones worth a slot.

Safe sync

Review every change, then watch each slot written and confirmed. Only edited slots change.

Generate on the desktop

Pick a character, shape it, and keep a sound in a slot or in a library.

Light, dark, AMOLED

Three themes on every platform, with large text and screen readers supported.

Try it without a synth

The simulated synth answers like a real one, with no sound. You need Rust 1.92 or newer.

git clone https://github.com/oscyl/oscyl && cd oscyl
cargo run -p oscyl-cli -- --simulator info    # Linux, macOS, Windows
cargo run -p oscyl-gtk -- --simulator         # the Linux app
