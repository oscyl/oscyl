# Getting help

- **Questions** (how do I, does Oscyl support, what does this setting do):
  ask in [Discussions](https://github.com/oscyl/oscyl/discussions), in the
  Q&A category.
- **Something is broken:** open a
  [bug report](https://github.com/oscyl/oscyl/issues/new?template=bug_report.yml).
  Say which app, which synth and which firmware.
- **A synth you would like supported:** open a
  [new synth request](https://github.com/oscyl/oscyl/issues/new?template=new_synth_request.yml).
- **An idea:** open a
  [feature request](https://github.com/oscyl/oscyl/issues/new?template=feature_request.yml),
  or start a thread in Ideas.
- **A security problem:** report it privately, as [SECURITY.md](SECURITY.md)
  describes. Never in a public issue.

Oscyl is made by volunteers. Answers come when someone has time, and a
clear report with steps to reproduce gets one sooner.
